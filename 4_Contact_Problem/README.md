# 4_contact_problem_1st_Order
This program solves the Sod Shock Tube Problem using the Peter Jacobs Riemann Solver.

More informations are in [here](./4_contact_problem_1st_Order/README.md)

# 4_contact_problem_2nd_Order
This program resolves the 4-contact problem using second-order reconstruction.

More informations are in [here](./4_contact-problem_2nd_Order/README.md)

# 4_contact_problem_2nd_Order_GPU
This program applies CUDA acceleration to parallelize the 2nd-order 4-contact problem solver.

More informations are in [here](./4_contact_problem_2nd_Order_GPU/README.md)
