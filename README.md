## CFD Practice
This directory stores practice code and snippets for future reference.

More informations are in [here](./CFD_Practice)

## Shock Tube Probelm
I implemented three different solver formulations and validated and benchmarked them using the Sod shock tube problem.

More informations are in [here](./Shock_Tube_Problem)

## 4 Contact Problem
This program solves the classic 2D Riemann problem using the Peter Jacobs Riemann Solver.

More informations are in [here](./4_Contact_Problem)

## Boiling Water Problem
This program is primarily used to test my solver and verify that the flux calculations for the air-water gas mixture are working properly.

More informations are in [here](./Boiling_Water_Problem)

## FOUP
This program represents the final practical engineering problem I aim to simulate:

investigating whether installing an air curtain in front of a semiconductor FOUP can effectively block moisture from entering and affecting the wafers stored inside.

More information are in [here](./FOUP)
